## 🛠️ Application Installation and Dependencies

### Prerequisites

Before starting, make sure you have the following installed on your system:

- **Python 3.9 or higher**
- **pip** (Python package manager, usually included with Python)

You can verify this by running the following commands in a terminal or console:

python --version  
pip --version

### Download the Project

#### Option 1: Clone with Git

git clone "https://github.com/MiguelNievesA/Py-Dex"  
cd Py-Dex (<repository-name>)

### 📦 Install Dependencies

To automatically install all project dependencies, use the **requirements.txt** file and run:

pip install -r requirements.txt

Once the dependencies are installed, run the main project file:

python main.py

### Common Errors and Solutions

* `ModuleNotFoundError`  
  One or more dependencies are not installed. Review the dependencies section.

* `The application window does not open`  
  Make sure PyQt5 is correctly installed and that you are running the main file.

* `Version conflicts`  
  Always use a clean virtual environment to manage dependencies and avoid version conflicts.

## Recommendations for Reporting Issues

To help fix bugs more efficiently, please review the official project documentation before opening an **issue**.

If you confirm that the problem is a **real bug in the project**, please provide the following information clearly and in order:

1. **Operating system**  
   Specify the operating system and version (e.g., Windows 11, Ubuntu 22.04, macOS Sonoma).

2. **Library versions used to run the project**  
   Specify the exact application version and the libraries installed to run it.

3. **Minimal reproducible code**  
   Include the smallest possible code example that reproduces the issue. Avoid sharing full projects unless necessary.

4. **Steps to reproduce the issue**  
   Describe step by step what actions are required for the problem to occur.
